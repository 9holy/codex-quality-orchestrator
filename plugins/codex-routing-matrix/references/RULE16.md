## Codex Quality Routing - Default Multi-Model Quality Team

- Use only with a `gpt-5.6-sol` root. Handle clear, low-risk short work directly; risk overrides size.
- For non-short work, Sol owns planning, decomposition, ownership, integration, verification, decisions, and fallback. List bounded units.
- Delegate only with reliable capability and net benefit. Use `luna_worker` only for frozen, low-judgment, mechanically verifiable work; when reliable, MUST choose `luna_worker`. Never trial uncertain work on Luna.
- Sol keeps ambiguity, unresolved causes, architecture, security, public interfaces, production data, irreversible operations, and final judgment. Delegate only after boundaries and acceptance are clear.
- When Luna is unsuitable, use `sol_medium_worker` for bounded, moderate-judgment, independently verifiable work when delegation or parallelism pays; else keep current Sol. Do not create it merely to change effort.
- Terra is not an escalation step; deep reasoning alone never selects it. Use `terra_worker` only for a clear task-specific quality, context, concurrency, or total-cost advantage over capable Sol Medium or current Sol; use its lowest reliable effort.
- Use Radar once at most per root task only for an unresolved choice among capable Sol/Terra routes. An IQ gap >= 3 selects higher IQ; otherwise keep the hot/original agent, then lower total cost. Freeze each route until relevant facts change.
- Default to one Worker. Parallelize independent, write-safe units only when beneficial. For homogeneous batches, verify one unit, fill host capacity, and replace completed Workers. Use one blocking wait; never poll. One writer per file; Workers never delegate. No task-wide cumulative cap.
- Sol MUST inspect every Worker result or diff and rerun needed checks. One clear local defect may return once; capability, scope, or quality failure returns to Sol. Use one read-only `sol_reviewer` only for critical review.
- On exact `Selected model is at capacity. Please try a different model.`, resume the same agent once without restarting work. A second failure returns to Sol; never switch silently or resume capability/quality failures.
- Preserve the root model and reasoning effort. The only Sol subagents are `sol_medium_worker` for eligible execution and `sol_reviewer` for critical review. Follow `$codex-quality-routing-team` contracts; never pass `model`.
- Super mode is off by default. Exact commands `开启爆种模式` / `enable super mode` and `关闭爆种模式` / `disable super mode` toggle the current session. When off, use normal routing: no burst fields or depth delegation; default to one Worker and let the current Sol handle final review. When on, Sol is `d0`; independent write-safe units may use `d1`-`d4`; `d4` must not delegate. Every super-mode packet states `burst_depth=dN` and `burst_delegate=yes`; task names contain `__dN_`. Use up to 25 child threads, refill completed units, keep all quality gates, and let Sol audit, integrate, and fall back.
